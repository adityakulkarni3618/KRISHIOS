# Adapting to a hackathon / SIH problem statement
1. Copy the OFFICIAL text and URL into `research/problem_statement_catalog.csv` (never invent one).
2. POST it to `/mapping/classify`; human-review the suggested domains/modules.
3. Add a row per requirement to `docs/TRACEABILITY_MATRIX.md`.
4. Enable only needed modules; build the gap (one vertical slice); test; record evidence.
5. Write the proposal sections (interpretation, users, architecture, novelty, data, metrics, risks, impact, demo script, limitations) using only evidenced claims.
