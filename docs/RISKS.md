# Risks, unknowns, partnerships
- **Scope risk (highest):** 20 modules for a student team. Mitigation: MVP only; modules stay NOT IMPLEMENTED until evidenced.
- **Data access:** Agmarknet/e-NAM/IMD API access, terms and rate limits are unverified. May need API keys or partnerships.
- **ML validity:** Lab-image disease datasets generalise poorly to field photos. Need field images and expert labels.
- **Agronomic correctness:** wrong advice harms farmers. Need KVK/SAU expert review; cite sources.
- **Language quality:** machine translation of agri terms needs native review.
- **Legal/privacy:** DPDP Act; no impersonating government services.
- **Maintenance:** one-student bus factor; keep infra simple.
- **Partnerships needed:** Krishi Vigyan Kendra / agricultural university (validation), FPO (pilot users), data providers.
