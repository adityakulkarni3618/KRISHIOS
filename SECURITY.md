# Security
Current state: **In active development (MVP); not for production deployment.** No public unauthenticated access in production. Planned (Milestone 1b): password hashing (argon2), JWT or session auth, role-based access (farmer/expert/FPO/provider/researcher/admin), rate limiting, upload validation (type, size, re-encode images), audit log, secrets via environment only, dependency scanning in CI. Report vulnerabilities privately to the maintainers (add contact before public release).
